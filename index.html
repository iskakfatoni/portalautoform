Ekspor Data & Link Guru ke Excel

Unduh file Microsoft Excel asli (.xlsx) yang berisi daftar seluruh guru lengkap dengan link portal personal, link auto-fill, dan link jurnal mereka.

File Excel ini dapat dibuka langsung di Microsoft Excel atau Google Sheets dan siap dibagikan ke masing-masing guru.

Impor Data Guru dari Excel

Unggah file Excel (.xlsx / .xls) atau CSV untuk menambahkan atau memperbarui data NIP, kelas binaan, dan link jurnal banyak guru sekaligus.

Pilih atau Tarik File Excel (.xlsx / .xls) ke sini

Panduan Penggunaan Sistem

Petunjuk lengkap bagi Guru dan Administrator

1

Link Personal Khusus Guru

Setiap guru memiliki URL unik, misal: ?nip=198109092022211004. Saat link dibuka, portal langsung menampilkan nama dan kelas yang bersangkutan tanpa perlu memilih lagi.

2

Impor & Ekspor Data Massal

Admin dapat mengekspor daftar guru ke file CSV untuk dibagikan, atau mengimpor data CSV untuk memperbarui NIP dan kelas guru secara bersamaan.

3

Manajemen Database Cloud

Semua perubahan data guru dan formulir langsung tersinkron secara realtime ke database Cloud Firestore.
