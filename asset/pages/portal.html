Panduan Penggunaan Sistem

Petunjuk lengkap bagi Guru dan Administrator

1

Link Personal Khusus Guru

Setiap guru memiliki URL unik, misal: ?nip=198109092022211004. Saat link dibuka, portal langsung menampilkan nama dan kelas yang bersangkutan tanpa perlu memilih lagi.

2

Impor & Ekspor Data Massal

Admin dapat mengekspor daftar guru ke file CSV/Excel untuk dibagikan, atau mengimpor data untuk memperbarui NIP dan kelas guru secara bersamaan.

3

Sinkronisasi Cloud Firebase

Seluruh perubahan data guru dan formulir tersimpan aman di Cloud Firestore dan langsung diperbarui di semua perangkat secara real-time.
